# Before you begin

You can read the lessons and follow the [museum pictures](../demo/WALKTHROUGH.md) without installing anything. To make your own version, start with a small app that already works.

## Get the starter working

Follow the [setup guide](../curriculum/SETUP_AND_VERSIONS.md) to open the official PICO starter in your own working folder. A coding assistant can edit and build it for you. If you use ChatGPT in a browser, you will use Android Studio to save and build the edits yourself. The PICO SDK supplies the tools for making PICO apps.

Build and open the untouched starter first. A **build** turns your code into an installable app; opening it lets you see what it actually does. If this first step fails, keep the error message and get setup help before adding museum features.

The old museum source folders are for comparison. The earliest draft is not a complete starter. Your new starter will not yet contain the museum’s objects, screens or stories.

## Work with ChatGPT

In the browser route, paste the starter text named in the setup guide, with each filename above it. ChatGPT cannot read a file on your computer from its name alone. Keep using the same conversation, and share the latest version whenever you change something.

The assistant can suggest edits; you put them into Android Studio. With the [coding-assistant route](../curriculum/SETUP_AND_VERSIONS.md), it can read and edit your working folder for you.

## Repeat one small loop

1. Ask for one change using a request from the lesson.
2. Save the suggested edit, keeping a copy of the version that worked.
3. Build and open the app using the setup guide, then try the lesson’s check.
4. If the result is wrong, share what happened and ask for one correction.

Stop adding features while a change is broken. Use the exact error or a screenshot instead of guessing what caused it.

The models arrive in [a separate download](../ASSET_SUPPLEMENT.md). Get them when Lesson 2 asks for them; a simple box is useful practice but is not the finished museum object.

Start [Lesson 1 — A small idea](L0.md). The [request library](../prompts/PROMPT_LIBRARY.md) has all the practice wording in one place.
