# Lesson 1 — Start with a small idea

**Your goal:** decide what your first museum screen should do.

Imagine choosing an everyday object and finding a story in it. We will begin with a tumbler, a robot vacuum and a smart speaker. Later, you will add stories and a room with eighteen exhibits.

You can do this first lesson with ChatGPT in your browser. Open the [museum walkthrough](../demo/WALKTHROUGH.md) to see where the course is heading.

## Describe what you want

> Help me plan a small museum with a tumbler, a robot vacuum and a smart speaker. I want to choose an object, read about it and see it in 3D.

Read the answer and sketch the screen on paper. Can you point to the three choices, the description and the object? Cross out extra features you do not need yet. Your sketch can be rough; its job is to make the idea clear.

## Get to know your starting app

When you are ready to build, follow [Before you begin](PREPARE_TO_BUILD.md). Start with the official PICO starter that already opens on your setup.

Paste the starter text identified in the setup guide into ChatGPT, with the filenames above it. Then ask:

> Here is the starter I can already run. Explain what it shows now and the smallest change we could make first.

Compare the answer with the app you opened. It should describe what is actually there. You do not need to know the names of the museum’s future code files.

If the explanation is still confusing, point to the part you do not understand:

> This explanation is too technical for me. Explain it using what I can see on the screen.

## What happened in the original project

The museum began as a browser design. Its first prepared app code still needed setup and corrections before it could run on PICO. That early code is useful to [read](reference-L0.md), but it is not the working starter for this course.

## Try it yourself

Tell someone what should change when they choose the vacuum. If they can picture it, keep those two or three sentences beside your sketch.
