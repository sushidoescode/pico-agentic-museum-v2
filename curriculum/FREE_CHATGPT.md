# Following along in a normal ChatGPT chat

You can discuss the idea and try the short lesson prompts without a Pro account. Building the app still needs PICO's tools on a computer.

The main lessons work best with a coding assistant connected to your project. In a normal browser chat, **you do the file editing and run the tools**. An instructor can help with those parts.

## One change at a time

1. Complete [setup](SETUP_AND_VERSIONS.md), then open your working project.
2. Send the lesson's first request.
3. When ChatGPT needs a file, paste its contents with the filename above them.
4. Ask for the whole updated file and where to save it.
5. Save your old version, copy in the new one, and build the app.
6. Try the change. Send the actual error or describe what you saw before asking for another feature.

If uploads are unavailable, paste a small relevant file instead. Keep [your notes](MY_BUILD_NOTES.md) so you can resume later. Check OpenAI's [Free Tier FAQ](https://help.openai.com/en/articles/9275245-chatgpt-free-tier-faq) for current limits and model access.

## What our Luna attempt showed

On October 7 we tried short requests with GPT-5.6 Luna through a paid Codex account. It produced a smaller prototype that compiled, with fifteen feature tests and one starter test passing. It needed repairs and experienced help supplying files and explaining errors.

That attempt did not reproduce the finished museum, run inside a free ChatGPT account, or demonstrate the app in PICO. Its [actual requests and results](../reproduction/README.md) are kept as an optional example of iteration. They are not a promise that these lessons have been completed successfully by a beginner on the free plan.
