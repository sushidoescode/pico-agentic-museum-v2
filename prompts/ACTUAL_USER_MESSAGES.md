# Feedback from building and testing the museum

These are four unchanged excerpts from two saved user messages. They focus on trying the app and asking for improvements. Spelling and wording are left as written.

The first message is from September 28. The other three excerpts are from **one follow-up message on October 13**, after the first draft. They were not three separate build steps.

## Try the demo yourself — September 28

> That was me testing the demo; emulator is free now, continue

The owner had tried the demo and was ready for the app agent to continue.

## Make moving around clearer — October 13

> I think for now adding teleport circles is very important. Especially using hand tracking, something that uses gaze that highlights where you're looking at and pinch to teleport to that item would be a great experience especially on the device itself, but on the emulator, I'm assuming navigation by clicking to teleport to the item for a close look also makes sense, because I don't think it's possible to test hand tracking on the emulator.

This asks for clear places to move to and a way to select them on each setup. The comment about emulator support is an assumption in the message.

## Try the suggested window — the same October 13 message

> That being said, authorizing a new build is fine with me and if we want to use PICO's subwindow idea and implement to see how it would work on the emulator that would be great too.

This asks the app agent to try PICO's window suggestion in a new build.

## Soften the transition — the same October 13 message

> The device look, I would ask that the short fade would be a cool way to show the transition.
