# Start here

The main entry point is the [README](README.md). It explains the product and the course, and offers three routes:

1. **See the walkthrough:** open `demo/index.html` locally in a browser, or read [demo/WALKTHROUGH.md](demo/WALKTHROUGH.md).
2. **Learn the process:** [First steps with an AI assistant](curriculum/FIRST_STEPS_WITH_AI.md), then the [course map](curriculum/COURSE_MAP.md).
3. **Inspect the code/setup:** [source snapshots](source/SNAPSHOTS.md) and [setup and versions](curriculum/SETUP_AND_VERSIONS.md).

Use [PROGRAM_INGREDIENTS.md](PROGRAM_INGREDIENTS.md) to find any part of the program. [ASSET_SUPPLEMENT.md](ASSET_SUPPLEMENT.md) explains which files come separately. Current build identities and limits are in the [evidence index](evidence/INDEX.md) and [open items](review/OPEN_ITEMS.md).

The original review package opened with a longer summary in this file. That version is unchanged inside the original package; in this repository the README replaces it.
